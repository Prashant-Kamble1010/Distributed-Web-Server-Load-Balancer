DCS Mini-Project: Concepts & Viva Quick Reference
1. What is Round-Robin Load Balancing?

Round-Robin is a deterministic scheduling algorithm that assigns incoming client requests to available servers in cyclic sequential order (A → B → C → A ...).

2. How is Fault Tolerance handled?

When a node is offline (simulated failure), the load balancer automatically skips it during the rotation cycle and passes the request to the next healthy node. If all servers fail, the load balancer gracefully returns HTTP 503 (Service Unavailable).

3. How is Thread Safety guaranteed?

The scheduling pointer and server counter increments are protected by synchronized blocks and atomic primitives (AtomicLong), preventing race conditions under concurrent client requests.

4. Simulated vs Production Distributed Systems:

In production, a load balancer (such as NGINX or HAProxy) sits on a dedicated reverse-proxy host forwarding TCP/HTTP traffic to separate virtual machines or containers. In this educational project, backend nodes are simulated thread-safe objects within a single Spring Boot container to avoid external infrastructure dependencies.
